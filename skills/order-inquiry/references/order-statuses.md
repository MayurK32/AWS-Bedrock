# Order Status Definitions

| Status             | Meaning                                                    |
|--------------------|------------------------------------------------------------|
| `pending`          | Order received and confirmed, not yet shipped.             |
| `delivered`        | Order has been delivered to the customer's address.        |
| `not-shipped`      | Order confirmed but shipment has not been initiated yet.   |
| `return-inprogress`| Return request submitted; pickup or refund is in process.  |
